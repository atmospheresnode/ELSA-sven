It used to live inline in bundle.html, which meant the panel refreshed itself when a check finished and this did not: the window went on showing whatever was true when the page loaded, including a stale warning that had since been answered and a Submit button disabled on it. {% endcomment %}
{% comment %} Two parts. The checking band is shown while a check runs, including one this window starts for itself when it opens on a bundle that has changed since its last check. The result replaces it when the check finishes. The result reads the submission gate (validation_block), the same answer the Submit button and submit_bundle_internal use, so the band cannot say "ready" while the button refuses, or the other way round. {% endcomment %}
