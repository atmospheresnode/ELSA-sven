{% comment %} One inspector window shared by every NetCDF file on the page, opened by a file's View button in a collection's NetCDF card or in the Files Not In Any Collection pane. A browser cannot show a .nc file, so instead of handing back the file the user just uploaded, this answers what they actually want to know: what is in it (xarray's notebook view of the header, from build:netcdf_inspect) and what ELSA made of it (the PDS4 label). Download stays available in the header, through build:netcdf_file. Nothing is fetched until the window opens, and each file is fetched once per page load. Triggers carry data-nc-name, data-nc-inspect-url and data-nc-download-url. Include once per page, outside any card or collapse. {% endcomment %}
