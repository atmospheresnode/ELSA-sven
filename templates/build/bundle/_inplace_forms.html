{% comment %} The bundle page's windows save in place. Any form here marked data-inplace="" is posted by this script instead of by the browser, with the name in X-Elsa-Inplace. The view answers in JSON (build/views.py, _inplace_form and friends): {ok: true, redirect: url} saved: go there (normally this page, so it reloads with the confirmation toast and the right tab open) {ok: false, errors: {...}} refused: Django's form errors, keyed by field name A refusal is shown inside the window, which stays open with everything the user typed and the file they picked still in it. Before this, a refused document add on an External bundle left the bundle page for a walkthrough page with no way back, and a refused alias or modification history reloaded the page with the reasons hidden in a closed window. Without fetch or FormData, or with JavaScript off, the forms post as they always did; the views still handle that. {% endcomment %}
