{% comment %} Django messages, as toasts. Replaces the full-width dismissible alert that used to be pushed in at the top of the page body. That pattern had three problems, all of them worse because the AMA save ends in window.location.reload(): the notice appeared at the top of the document, nowhere near the modal the user had just been working in; it shifted the whole page down as it arrived; and it sat there until dismissed by hand. A toast is the modern form of the same thing. It overlays rather than displaces, it appears in a consistent corner whatever page it is on, and a success can take itself away. Placed outside every card, column and theme wrapper, for the same reason the project's modals are: a fixed element nested inside a themed container inherits button recolouring it has no business inheriting. Severity decides whether it leaves on its own. A success is confirmation of something the user just did deliberately and needs no acknowledgement, so it goes after a few seconds. A warning or an error is news, usually about something that did not happen, which is exactly the case where a notice that vanishes is how a user comes to believe the save worked. Those stay until dismissed. {% endcomment %} {% if messages %}
